This file vendors the ISC license terms covering OpenBSD's openrsync
(https://github.com/kristapsdz/openrsync) — used here as the canonical
reference for porting protocol-state-machine code into ssh-mcp's
`src/adapters/rsync/wire/` module tree (ADR 0011).

Files in `src/adapters/rsync/wire/` ported from openrsync carry an
`SPDX-License-Identifier: ISC` line and a header block referencing this
notice. The Rust port maintains openrsync's struct names + field order
to ease cross-references against the C source; the I/O layer is
rewritten to async + lock-free Rust per the project's hot-path
invariants.
