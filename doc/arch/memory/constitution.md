# ssh-mcp Constitution

This document establishes the foundational principles and governance model for
the ssh-mcp project. It guides every decision about scope, contribution, and
evolution of the system.

ssh-mcp is a subscribe-first SSH MCP server (`README.md:3`) shipped as a single
package (version 7.1.3, edition 2024, MSRV 1.99 — `Cargo.toml:14-16`) on a
hexagonal core of six layers: `domain`, `ports`, `application`, `adapters`,
`infra`, `composition` (`docs/ARCHITECTURE.md:104-113`). Its published surface
is the MCP tool catalogue, the block-markdown response envelope and the error
taxonomy (`REVIEW_CHECKLIST.md:27-31`).

The **Doctrines** section holds the mandatory `D-NN` set of the speckit doctrine
catalog, regenerated by `speckit constitution` and never hand-edited (`speckit
doctrine list`). The **Principles** section holds the project's own `P-NN` rules,
authored here, and every mandate cites the repository file and line that states
it. Where a doctrine and a principle cover the same ground, both stand, and the
doctrine keeps its own severity (`speckit manual --topic validators`).

## Doctrines

## D-01 — Spec first
Severity: block
MANDATE: A feature is specified, planned and tasked before any production code is written, and the corpus is the source of truth over code and assumption. Run the lifecycle in order (specify → clarify → plan → tasks → implement) and keep the feature artifacts current.
Enforced by: llm-context.spec-first.missing, constitution.doctrines.missing, verify
## D-02 — Dogfooding
Severity: block
MANDATE: The project validates itself with its own commands and keeps the dogfood gate green; a rule that is right for consumers is right for the project. Run `speckit validate` and `speckit verify` before every commit; fix the artifact, never the rule.
Enforced by: arch_boundaries, validate, constitution.principle.duplicate
## D-03 — Hexagonal layering
Severity: block
MANDATE: Dependencies point one way: infrastructure to application to ports and domain, with the domain free of I/O. Tag the model element with its layer, break the cycle, and move the import to the allowed direction.
Enforced by: hexagonal.illegal-dependency, hexagonal.dependency-cycle, arch_boundaries, hexagonal.layers.untagged, layers.inward-import, layers.unknown-dir, layers.undeclared-import, layers.undeclared-dir, layers.cycle, layers.self-edge, layers.duplicate-edge, core.crate-denied, core.orm-import, core.crate-unadjudicated
## D-04 — Domain-driven design
Severity: block
MANDATE: Every model element declares its tactical role and every bounded-contact relationship declares one strategic kind. Declare the role, the aggregate root, the context pattern, and the typed context edge; fix membership and repository returns.
Enforced by: ddd-role.header.missing, ddd-role.role.unknown, ddd-tactical.missing-role, ddd-tactical.entity-identity, ddd-tactical.value-object-holds-identifiable, ddd-strategic.unknown-relationship, ddd-strategic.mutually-exclusive, ddd-strategic.mixed-relationship-sides, ddd-strategic.mixed-relationship-kinds, ddd-strategic.relationship-via-ref, ddd-strategic.relationship-deprecated, ddd-strategic.two-sources, context.pattern-missing, context.pattern-unknown, context.edge-untyped, context.property-orphan, context.on-layered-container, context.edge-reversed, context.kind-unknown, context.role-unknown, context.multiple-downstream-roles, context.roles-on-symmetric, context.conformist-in-customer-supplier, context.ohs-in-customer-supplier, context.acl-in-customer-supplier, aggregate.membership-missing, aggregate.root-unknown, aggregate.multiple-roots, aggregate.member-before-root, aggregate.cross-reference-object, repository.returns-member, repository.returns-tuple, doctrine.source-missing
## D-05 — Object Calisthenics
Severity: block
MANDATE: Entities stay small, names stay meaningful, nesting stays shallow, and primitives and collections are wrapped. Split the entity, rename the binding, extract the nested block, and wrap the bare primitive or collection.
Enforced by: calisthenics.small-entities, calisthenics.no-abbreviation, calisthenics-code.small-entities, calisthenics-code.no-abbreviation, calisthenics-code.nesting-depth, calisthenics-code.getter-setter, calisthenics.wrap-primitives, calisthenics.first-class-collection, calisthenics.one-definition-per-file, calisthenics-code.wrap-primitives, calisthenics-code.first-class-collection, calisthenics-code.one-type-per-file, calisthenics-code.no-else, branch.else, chain.one-dot, comment.implementation-in-interface, comment.repeats-code, condition.negative, interface.fat, literal.magic-number, name.hard-to-describe, name.vague, switch.type-code, type.boolean-flag, inheritance.depth, calisthenics-code.two-instance-variables
## D-06 — Fully qualified names
Severity: block
MANDATE: Every first-party production import is a full `crate::…` path; glob imports and `crate::domain::` are test-only conveniences. Replace `use x::*;` with the named items, `use crate::domain::y` with its `crate::…` path, and a `../` or sibling include with its full path from the code root.
Enforced by: fqcn.glob-import, fqcn.relative-super, fqcn.partial-include
## D-07 — Enforced lints and exact pinning
Severity: block
MANDATE: Every detected ecosystem ships its lint configuration at the strongest level and pins its dependencies exactly. Commit the lint configuration and replace every range or floating version with an exact pin.
Enforced by: lint.rust.lints-missing, pin.cargo.lockfile-missing, pin.docker.unpinned-image, pin.ci.unpinned-action
## D-08 — Fail loud
Severity: block
MANDATE: Production code never panics on recoverable absence: `unwrap` and `expect` are denied, and an error is propagated or typed. Return a `Result`/`Option` up the stack, add a typed domain error, or handle the absence explicitly.
Enforced by: calisthenics-code.bare-unwrap, no-unwrap, clippy
## D-09 — Declared licence
Severity: block
MANDATE: A project declares its licence id and commits a matching `LICENSE` file; the two never drift. Run `speckit license set <id> --write-file` and keep the declared id equal to the committed text.
Enforced by: project-license.file.missing, project-license.fingerprint.mismatch
## D-10 — Guard-mediated writes
Severity: block
MANDATE: Every mutating command asks the guard before it writes, and the write lands inside the active scope. Call `GuardService::enforce_write` before the `FilesystemPort` write and surface the verdict as exit 4.
Enforced by: guard
## D-11 — Stable contracts
Severity: block
MANDATE: The published surface — exit codes, `--json` shapes, and declared artifact contracts — moves only additively. Add a field instead of renaming one, keep the exit table intact, and give every operation an id.
Enforced by: contract.info.missing, contract.operation.id-missing
## D-12 — Small changes
Severity: advisory
MANDATE: One concern per change: a commit, a branch and a review stay reviewable in one sitting. Split the work by concern, use the Angular commit header as the summary, and let the size advisories keep one unit from swallowing the change.
Enforced by: function.long, function.long-parameter-list, module.pass-through, module.special-general-mix, module.shallow
## D-13 — Offline by default
Severity: block
MANDATE: The core loop validates, phases and guards without the network; a network path is opt-in and degrades. Keep network access behind a port and a flag, and let a missing network fall back to the local behaviour; the core call table holds `std::net::` out of the core.
Enforced by: core.io-direct
## D-17 — Reproducible dependency surface
Severity: advisory
MANDATE: A library publishes an exact, lockfile-anchored dependency set so a consumer resolves what its author tested. Commit the lockfile and pin direct dependencies to exact versions.
Enforced by: pin.cargo.lockfile-missing

## Principles

## P-01 — Inward dependencies and static dispatch
Severity: block
MANDATE: An import points inward through the six declared layers, and the layer table in `docs/ARCHITECTURE.md` names what each layer holds and what it is denied. `domain` stays pure: no Tokio, no I/O, no async. Ports are pure traits, use cases stay generic over their ports, and the composition root pins one concrete adapter per port, so a wiring error surfaces at `cargo build`. An adapter never calls another adapter directly; the call crosses through the use case. No `Box<dyn Trait>` on a hot path, and an async port uses the `trait-variant` AFIT surface. Sources: docs/ARCHITECTURE.md:104-113, docs/ARCHITECTURE.md:115-118, REVIEW_CHECKLIST.md:19-20, CONTRIBUTING.md:39
Enforced by: layers, arch_boundaries
## P-02 — Lock-free hot paths
Severity: block
MANDATE: Every shared producer and consumer path on the hot path is lock-free: `DashMap`, `ArcSwap`, `OnceCell`, `Atomic*`, `tokio::sync::broadcast`, `tokio::sync::Notify`, and `mpsc` channels for owned-resource serialization. No hot-path state type carries a `Mutex` or `RwLock` field, and the manifest denies the lints that would let one in. A change that touches hot-path atomics or `ArcSwap` ships a loom invariant under `tests/lockfree_invariants*.rs`, gated `#[cfg(loom)]`. Sources: Cargo.toml:204-209, REVIEW_CHECKLIST.md:15, CONTRIBUTING.md:57, CONTRIBUTING.md:63, docs/DEVELOPMENT.md:71, docs/DEVELOPMENT.md:129
Enforced by: clippy
## P-03 — Panic-free production code and justified suppressions
Severity: block
MANDATE: Production code never calls `unwrap`, `expect`, `panic!`, `todo!`, `unimplemented!`, `dbg!`, `print!` or `eprintln!`; an absence is propagated as `Result` or `Option`, or typed as a domain error. A match on a closed enum stays exhaustive, with no `_ =>` catch-all. Every `#[allow(...)]` carries a `reason = "..."`. A lint is never silenced, and a test is never ignored, to make the gate green. Sources: Cargo.toml:158-167, Cargo.toml:177, Cargo.toml:201, CONTRIBUTING.md:29, CONTRIBUTING.md:37, CONTRIBUTING.md:38, docs/DEVELOPMENT.md:70, docs/DEVELOPMENT.md:76, docs/DEVELOPMENT.md:83, REVIEW_CHECKLIST.md:13-14, REVIEW_CHECKLIST.md:21, CI.md:108
Enforced by: no-unwrap, clippy
## P-04 — The MCP wire is a frozen contract
Severity: block
MANDATE: The published MCP surface stays byte-identical for every existing consumer: tool names, the block-markdown envelope (`TOOL_NAME: STATUS` first line, one `KEY: value` per line, `_ID` suffixes, `--- name [nonce] ---` output headers), the `structured_content` twin, resource URIs, environment-variable defaults, and the error taxonomy. A new error code joins one of the seven categories of ADR 0007 with declared retry semantics before it is emitted. Exact-string render tests pin the current render of the envelope — `src/infra/mcp/helpers/output.rs::tests::render_output_block_with_content` and `src/infra/mcp/render/connection.rs::tests::disconnect_render_emits_block` — and stay green; no test compares a response with a capture from an earlier release. Sources: REVIEW_CHECKLIST.md:27-31, REVIEW_CHECKLIST.md:52, src/infra/mcp/helpers/output.rs:245-248, src/infra/mcp/render/connection.rs:881-890, docs/ARCHITECTURE.md:3, docs/adr/0007-error-taxonomy.md:32, docs/adr/0007-error-taxonomy.md:38, doc/arch/quality/quality-scenarios.md:81-89
Enforced by: verify
## P-05 — Wire additions are additive and opt-in
Severity: block
MANDATE: The wire grows by addition only, and every addition is opt-in: a new tool, a new argument that defaults to the current behaviour, or a capability advertised at `initialize` and echoed by the client. A host that does not opt in sees exactly the wire it saw before. No existing tool argument, response line, default or notification method is edited in place. Sources: docs/adr/0012-inline-push-notifications.md:62, docs/adr/0012-inline-push-notifications.md:131, docs/adr/0012-inline-push-notifications.md:254, docs/adr/0012-inline-push-notifications.md:360, REVIEW_CHECKLIST.md:37, CONTRIBUTING.md:62
Enforced by: verify
## P-06 — The verified-change gate
Severity: block
MANDATE: `make gates` is the definition of done for any change: `cargo fmt --all -- --check`, clippy with `-D warnings` (dev profile in a session through `make lint-dev`, release profile in CI through `make lint`), `cargo nextest run --lib`, and `cargo nextest run --tests --features test-fixtures`. Nextest is the only test runner. A failing test is fixed, not ignored, and no lint is disabled to make the gate green. Sources: Makefile:12, Makefile:92-96, Makefile:137-143, Makefile:155-161, CONTRIBUTING.md:21-31, CI.md:9-15, CI.md:105-108, docs/DEVELOPMENT.md:13, docs/DEVELOPMENT.md:38
Enforced by: validate, verify
## P-07 — A session builds in the dev profile
Severity: advisory
MANDATE: A session or a contributor runs the dev loop and stops at `make gates`: `make dev`, `make fmt`, `make lint-dev`, `make test`, `make test-integration`, `make check`. Release builds belong to the owner's install path; `make release`, `make release-min`, `make all`, `make install` and any `cargo build --release` are not session commands. CI owns the release-profile clippy gate. A change that appears to need a release build stops there and says so. Sources: Makefile:13-14, Makefile:74-75, Makefile:90-91, Makefile:98-109, Makefile:155-156, docs/DEVELOPMENT.md:27-29, session.md:140-141
Enforced by: (manual)
## P-08 — Commits and recorded decisions
Severity: block
MANDATE: A commit follows Conventional Commits, `<type>(<scope>): <subject>`, carries one logical change and its tests together, and lands only when the owner asks for it. A decision that spans more than one layer or changes a port surface is recorded as a MADR 4.0 ADR under `docs/adr/NNNN-<kebab-title>.md` before the code; an ADR number is never reused. Sources: session.md:138-139, CONTRIBUTING.md:41-51, CONTRIBUTING.md:61, CONTRIBUTING.md:73, CONTRIBUTING.md:102, REVIEW_CHECKLIST.md:63-66
Enforced by: madr
## P-09 — Persisted artifacts are en-US
Severity: advisory
MANDATE: Everything written to disk is en-US: identifiers, comments, log and error strings, commit messages, branch names, ADRs, and every document. A chat reply follows the language of the reader; the repository does not. The build environment forces `LANG`, `LC_ALL` and `LANGUAGE`, so compiler, linker and build-script output cannot drift with the host locale. Sources: CONTRIBUTING.md:11, .cargo/config.toml:25-29, session.md:142, Makefile:21
Enforced by: (manual)

## Governance

Changes to this constitution require a recorded Architecture Decision (MADR)
with status `accepted`, a non-empty `deciders` list, and an `amendments` entry
naming that ADR. Trivial corrections (typos, formatting) may be committed
directly. The MSRV pin and the frozen `Cargo.toml [lints.*]` tables move only
via accepted ADR.

A new ADR follows MADR 4.0, lives under `docs/adr/NNNN-<kebab-title>.md`, and
its number is never reused (`CONTRIBUTING.md:61`). A lint is never silenced to
make the gate green (`CONTRIBUTING.md:29`, `CI.md:108`).

Release authority sits with the maintainers listed in `MAINTAINERS`
(`MAINTAINERS:4`). A change that touches authentication, authorization, or
transport encryption carries an explicit reviewer acknowledgement from a
maintainer listed in `MAINTAINERS` (`REVIEW_CHECKLIST.md:59`). A box a reviewer
cannot tick blocks the merge until the code changes or the box is explicitly
waived in writing on the PR thread (`REVIEW_CHECKLIST.md:70`).

The licence is MIT, declared at `Cargo.toml:20` and committed at `LICENSE:1`.
